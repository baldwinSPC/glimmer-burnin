# Code of conduct

This project adopts the **[Contributor Covenant, version 2.1][cc]**, in full and
unmodified. Please read it there rather than here — a local copy is a copy that
drifts, and the canonical text is maintained upstream.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Report unacceptable behaviour privately to the maintainers listed in
[MAINTAINERS.md](MAINTAINERS.md), by opening a
[private security advisory][advisory]. It is the only private channel this
repository has, and it is appropriate to use it for this even though a conduct
report is not a security matter.

[advisory]: https://github.com/baldwinSPC/glimmer-burnin/security/advisories/new

Reports are handled by the maintainers, who will respect the reporter's privacy.
This project follows Kubernetes community conventions elsewhere and does so here.

## Scope

It applies in this repository — issues, pull requests, discussions, commit
messages and code review — and anywhere someone is representing the project.

## A note on technical disagreement

Robust technical argument is not a conduct problem, and there is a lot of it
here. Much of the review in this repository is about whether a claim is actually
supported by what was measured, and "this test would pass against broken code"
is a normal and useful thing to say about someone's work — including one's own.

That is criticism of the work. Criticism of the person is a different thing, and
it is what this document is about.
